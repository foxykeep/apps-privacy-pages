# Politique de confidentialité — FoxyJam

**Dernière mise à jour :** juin 2026

FoxyJam (« l'application ») est une application Android pour suivre vos confitures maison, publiée par [foxykeep](https://github.com/foxykeep).

## En bref

- **Aucun compte obligatoire** — l'application fonctionne hors ligne sur votre appareil.
- **Connexion Google facultative** pour sauvegarder et synchroniser vos données.
- **Pas de publicité** ni de vente de données personnelles.
- **Pas de SDK d'analyse** intégré à ce jour.

## Données sur l'appareil

Stockées localement :

- Lots de confiture (fruits, dates, poids, sucre, pectine, bocaux, notes)
- Composants de mélange et ingrédients supplémentaires
- Inventaire
- Préférences d'affichage (unités)

## Données cloud (connexion facultative)

Si vous utilisez **Se connecter avec Google** :

- Identifiants de compte via Firebase (ID utilisateur, e-mail et nom d'affichage en général).
- Vos données de confiture dans **Firebase Firestore**, accessibles uniquement à votre compte connecté.

Déconnectez-vous dans Paramètres pour arrêter la synchronisation.

## Utilisation des données

Uniquement pour faire fonctionner l'application, les suggestions et la synchronisation entre vos appareils. Pas de marketing.

## Services tiers

Google Sign-In, Firebase Authentication et Cloud Firestore (Google LLC). Voir la [politique de confidentialité Google](https://policies.google.com/privacy).

## Conservation et suppression

Les données locales restent jusqu'à suppression ou désinstallation. Pour supprimer les données cloud, contactez-nous.
